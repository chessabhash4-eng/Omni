OMNI OLYMPIARD — WEBSITE
========================

WHAT'S INSIDE
  index.html        → the full website (6 tabs)
  css/style.css     → styling, animations, responsive layout
  js/script.js      → menu, smooth scroll, counters, FAQ, form
  assets/logo.svg   → placeholder logo (SWAP THIS with your real logo)

HOW TO OPEN
  Just double-click index.html — it opens in any browser.
  Works offline, no installation needed.

REPLACE THE LOGO (important)
  1. Put your logo file in the "assets" folder.
  2. Easiest: rename your file to  logo.svg  (or logo.png) and replace
     the existing assets/logo.svg.
     - If your logo is a PNG/JPG, open index.html and change every
       src="assets/logo.svg"  to  src="assets/logo.png"
       (there are 3 spots: navbar, hero card, footer + 1 favicon link).
